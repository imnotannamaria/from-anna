# Goal
The goal of this project is pretty simple.

A few days ago, I got a notebook and realized it had been a while since I had actually **WRITTEN SOMETHING BY HAND** (lol). And with AI becoming such a big part of how we create things, I think a handwritten letter means even more now.

So I wanted to build something around that idea, while also using the project as an excuse to test some new technologies, like OpenRouter and Neon.

Basically: something personal, but also a playground for trying things I have not used before. :)
